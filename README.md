# Betül Sare — Portfolio (TR / EN)

## Çalıştırma / Run
    npm install
    npm run dev        # http://localhost:3000  (→ /tr veya /en)
    npm run build      # statik çıktı: /out

## İçerik / Content (hepsi TR + EN)
- data/site.ts          → isim, hero metni, iletişim
- data/experience.ts    → deneyim
- data/projects.ts      → projeler (sıra = sitedeki sıra, ilk 6 = büyük kartlar)
- data/certificates.ts  → sertifikalar (certificateUrl alanı hazır)
- data/skills.ts        → beceriler
- data/translations.ts  → arayüz metinleri
